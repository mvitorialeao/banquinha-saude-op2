# Banquinha da Saúde UFMG

Site estático em HTML, CSS e JavaScript, pensado para publicação no GitHub Pages.

## Arquivos

- `index.html` — estrutura e conteúdo do site
- `css/style.css` — visual e responsividade
- `js/script.js` — calendário, filtros de semanas, escala e menu mobile
- `imagens/` — coloque aqui fotos e logos reais

## Antes de publicar

1. Troque o botão "Abrir cadastro" pelo link real do formulário.
2. Atualize as datas e quantidade de voluntários em `js/script.js`.
3. Adicione fotos reais na pasta `imagens/` se quiser.
4. Revise os textos e endereços.
5. Faça upload para um repositório no GitHub.
6. Em Settings > Pages, escolha a publicação a partir da branch principal e da pasta `/root`.

## GitHub Pages

Depois da publicação, o endereço normalmente será:

https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

Para um site pessoal, também é possível usar um repositório chamado `SEU-USUARIO.github.io`.
